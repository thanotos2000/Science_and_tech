# 1.2 等离子体的定义

<mark style="background: #FF5582A6;">等离子</mark>体是<mark style="background: #FFF3A3A6;">带电粒子和中性粒子</mark>组成的表现出<mark style="background: #FFF3A3A6;">集体行为</mark>的一种<mark style="background: #FFF3A3A6;">准中性</mark>气体.

“集体行为”: 
- 考虑作用在一个分子（如普通空气的一个分子）上的力.  由于分子是中性的，不存在净电磁力，而重力可忽略. 一分子与另一分子碰撞前，它自由运动，碰撞决定了粒子的运动. 作用在中性气体上的宏观力（像扬声器产生的声波）通过碰撞传给单个原子. 
- 有带电粒子的等离子体中，情况完全不同． 电荷到处运动，能引起正、负电荷的局部集中，从而产生电场． 电荷的运动还产生电流，进而产生磁场． 电磁场再进一步影响远处其他带电粒子的运动. 从而表现出集体行为。
- 总结：前者为碰撞而后者为电磁场与物质的相互作用

- 我们考虑等离子体中相距为 $r$ 的两个稍许带电区域的相互影响 (图 1-1). 虽然 A 和 B 之间的库仑力随 $1/r^{2}$ 减小而减小. 然而，对给定的立体角 （即 $\delta r/r=const$)，B 中能影响 A 的等离子体体积随 $r^3$ 增加而增加. 所以, 即使相距很远的等离子体元也存在相互作用力. 正是这个长程库仑力给出了等离子体种类繁多的可能运动，并且丰富了称作等离子体物理学的研究领域. 事实上，最有意义的是所谓 “无碰撞”等离子体，其中，长程电磁力远大于与普通局部碰撞引起的作用，以至可以完全忽略后者. 
- “ 集体行为”这个词指的是不仅取决于局部条件而且取决于远距离区域等离子体状态的运动. 

# 1.3 重新看待温度

Q：温度的定义？A：气体分子热运动的平均动能。热运动？条件？

- 例如分子集体沿着某一同一方向运动，如一束离子束，此时，温度是否考虑该整体平动？显然，气体的温度只考虑构造质心系的内部的相对运动（无规则热运动）而不考虑整体的平动。好比一个水瓶在一架飞机上，当然不会因为飞机速度的改变升高温度。

- 热力学中，需要注意的是温度的定义是热平衡的条件下定义的。即分子的速度分布满足麦克斯韦分布（无外场）或玻尔兹曼分布（有外场）

麦克斯韦分布：
$$f(u)=f_0\exp{(-\frac{1}{2}mu^{2}/KT)}$$
e指数内，$\frac{1}{2}mu^2$ 为单个分子的动能。
- 麦克斯韦分布率实际是一个正态分布。

Q：麦克斯韦速率分布？
A：速率到速度实际上相当于从直角坐标（ $\overrightarrow{r}$ ）转换到球坐标系( $r$ )的过程. 
$$f(u)du=f(\mathbf{u})u^{2}sin \theta du$$
计算分子的平均动能
$$E_{av}=\frac{\int_{-\infty}^{\infty}\frac{1}{2}mu^{2}f(u)du}{\int_{\infty}^{\infty}f(u)du}$$
Def 
$$v_{th}=\sqrt{2KT/m},\quad y=\frac{u}{v_{th}}$$
有
$$f(u)=f_{0}\exp(-u^{2}/v^{2}_{th})$$
所以，平均动能
$$E_{av}=\frac{1}{2}KT$$
可以推广至三维
$$E_{av}=\frac{3}{2}KT$$
每个自由度的平均能量为$\frac{1}{2}KT$ 。由上面讨论，等离子体中温度往往用能量的单位来表示。

Note：
- 等离子体可以具有几个温度。比如说，
	- 离子之间和电子之间的碰撞率大于离子与电子的碰撞，因此可以说，每一种粒子都处于自身的热平衡中具有不同的温度。
	- 再者，尤其当存在磁场时，作用在粒子平行速度方向和垂直速度方向的作用力不同（洛伦兹力），因此垂直速度方向和平行速度方向会具有不同的速度分布率，因而具有不同的能量。
- 高的温度和很大的热量也并不一定相关。比如香烟的烟灰掉在手上并不一定热量很大，但其温度却足以燃烧。

# 1.4 德拜屏蔽

等离子体能够屏蔽作用在上面的电势。

假定在等离子体内插入两个和电池相连的带电球从而在等离子体内部引进一个电场。<mark style="background: #FFF3A3A6;">球会吸引相反电荷的粒子，几乎立刻就在负电球周围形成离子云，在正电球周围形成电子云。</mark> （我们假定，介电层实际上阻止了等离子体在表面上的复合，或者尽管存在着复合，但电池容量大到足够保持电势。）
- 若等离子体是冷的，不存在热运动，云中的电荷与球上的电荷相等。此时屏蔽是完全的，在云外面的等离子体内部就会不存在电场。 
- 若等离子体温度有限，处在云边缘 （电场较弱）的粒子就有足够的热能逃逸出静电势阱。 此时，云“边缘”在势能近似等于粒子热能 KT 的半径上，且屏蔽是不完全的。$KT/e$ 量级的电势能够漏入等离子体中并产生有限的电场。
