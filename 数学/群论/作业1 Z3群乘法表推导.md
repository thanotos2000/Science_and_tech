首先，一元素与元素e的乘积等于其本身, 所以乘法表如下:

| g1g2 | e   | d   | f   | a   | b   | c   |
|:---- |:--- |:--- |:--- |:--- |:--- |:--- |
| e    | e   | d   | f   | a   | b   | c   |
| d    | d   |     |     |     |     |     |
| f    | f   |     |     |     |     |     |
| a    | a   |     |     |     |     |     |
| b    | b   |     |     |     |     |     |
| c    | c   |     |     |     |     |     |

其次, 考虑 d 和 f 的乘法. d 为旋转120° , f 为旋转 240° , 所以 df 相乘旋转 360° 一周, 恰好转回原位, 元素 d, f 互逆. 
$$df=fd=e$$
![[数学/群论/附件-骆禹天的MacBook/Drawing 23-09-11 22.41.54.excalidraw]]

考虑 $dd$ 和 $ff$, 有: $dd=f,\quad ff=d$

![[数学/群论/附件-骆禹天的MacBook/Drawing 23-09-11 22.48.26.excalidraw]] ![[数学/群论/附件-骆禹天的MacBook/Drawing 23-09-11 22.53.50.excalidraw]]

再考虑 $aa$, $bb$, 和 $cc$ 操作, 其分别沿某一对称轴旋转 180° , 再旋转 180° , 转回原样. 所以
$$aa=bb=cc=e$$

将上面结果先汇总如下表: 

| g1g2 | e   | d   | f   | a   | b   | c   |
|:---- |:--- |:--- |:--- |:--- |:--- |:--- |
| e    | e   | d   | f   | a   | b   | c   |
| d    | d   | f   | e   |     |     |     |
| f    | f   | e   | d   |     |     |     |
| a    | a   |     |     | e   |     |     |
| b    | b   |     |     |     | e   |     |
| c    | c   |     |     |     |     | e   |

接着, 考虑 $da$ , 如下图所示:
![[数学/群论/附件-骆禹天的MacBook/Drawing 23-09-11 23.07.03.excalidraw]]
显然, 
$$da=b$$

由重排定理, 乘法表每行列的元素不能重复, 所以可依次补齐左乘 d 或 f 的两排结果. 比如, 计算 $fa$ 为例, 由于 d 行出现过元素 d, f, e, 而 a 列出现过元素 a, b, 所以 $fa=c$ . 

| g1g2 | e   | d   | f   | a   | b   | c   |
|:---- |:--- |:--- |:--- |:--- |:--- |:--- |
| e    | e   | d   | f   | a   | b   | c   |
| d    | d   | f   | e   | b   | c   | a   |
| f    | f   | e   | d   | c   | a   | b   |
| a    | a   |     |     | e   |     |     |
| b    | b   |     |     |     | e   |     |
| c    | c   |     |     |     |     | e   |

同理, 由于 $ad=c$ 
![[数学/群论/附件-骆禹天的MacBook/Drawing 23-09-11 23.18.57.excalidraw]]

故利用重排定理依次补齐左乘 d 或 f 的两列结果如下:

| g1g2 | e   | d   | f   | a   | b   | c   |
|:---- |:--- |:--- |:--- |:--- |:--- |:--- |
| e    | e   | d   | f   | a   | b   | c   |
| d    | d   | f   | e   | b   | c   | a   |
| f    | f   | e   | d   | c   | a   | b   |
| a    | a   | c   | b   | e   |     |     |
| b    | b   | a   | c   |     | e   |     |
| c    | c   | b   | a   |     |     | e   |

最后, 如下图有 $ab=f$ 
![[数学/群论/附件-骆禹天的MacBook/Drawing 23-09-11 23.23.48.excalidraw]]

得到上面结果后, 再用重拍定理可最终将所有元素补齐, 最后完整结果如下表:

|:---- |:--- |:--- |:--- |:--- |:--- |:--- |

| a    | a   | c   | b   | e   | f   | d   |
| b    | b   | a   | c   | d   | e   | f   |
| c    | c   | b   | a   | f   | d   | e   |
