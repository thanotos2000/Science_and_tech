# 5 变幻群，Cayley 定理，轨道与迷向子群

## 5.1 变幻群

### 完全对称群

设有一非空集合 $X=\{x,y,z,\cdots\}$ ，X 上的<mark style="background: #FF5582A6;">置换</mark> f 是将 X 映射到自己的一一满射$f:X\rightarrow X$  ，即对 $\forall x\in X$ ，有$f(x)=y\in X$ ，且f有逆$f^{-1}$，$f^{-1}(y)=x$ 。

再定义两个<mark style="background: #FF5582A6;">置换的乘积</mark> $fg$ 为先对X实行置换g，再实施置换f。
$$fg(x)=f(g(x))$$

X的全体置换在此乘法下可构成一个群，称为X上的<mark style="background: #FF5582A6;">完全对称群</mark>，记为 $S_{X}=\{f,g,\cdots\}$ 。
- 恒等置换e为$S_{X}$ 的单位元素
- 置换f与其逆置换$f^{-1}$为$S_{X}$ 的互逆元素。

### 变幻群

- 被变换的对象X的元素个数可以是有限的也可以是无限的和连续的。
	- 如三位欧式空间$R^{3}$ 中所有的点
	- 希尔伯特空间中所有态矢量9
- 当X元素使无限时，$S_{X}$ 是无限群，而当X有n个元素时，X的完全对称群$S_{X}$就是置换群 $S_{n}$。
- 完全对称群 $S_{X}$ 的任何一个子群都是X的一个对称群，又称为X上的<mark style="background: #FF5582A6;">变换群</mark>。

## 5.2 Cayley 定理

### 定理1.7 凯莱（Cayley）定理

群G同构于G的完全对称群 $S_{G}$ 的一个子群。特别地，当G是n阶有限群时，G同构于 $S_{n}$ 的一个子群。

证明思路：

只需要找到一个群，它是从G到G的双射即可。我们所学定理恰好给出过这样一个映射。

—— 重排定理

将群G中一个元素乘上每一个元素，可以完整得到且仅一次得到群G中的每一个元素。因此由该元素相乘的作用所代表的映射便是我们所寻找的双射。

## 5.3 轨道与迷向子群

### 等价和轨道

设 G 是集合 X 的一个变换群，如果 X 中的两个元素 $x,y\in X$ 可通过一个 $g\in G$ 联系：$gx=y$ ，则称元素 x 是 G <mark style="background: #FF5582A6;">等价于</mark>元素 y 的，或称 x 等价于 y，记为 $x\sim y$ .

从x点出发，经G变换后可以达到的所有点（即与它等价的所有点）的集合称为<mark style="background: #FF5582A6;">含x的G轨道</mark>。有时也简称为轨道。

### 不变子集

如果集合 X 中的某个子集 Y 在 G 的作用下不会跑出 𝑌 ，则称 𝑌 为 𝐺 <mark style="background: #FF5582A6;">不变子集</mark>。
显然 X 中每一个 𝐺 轨道是 𝐺 不变的，几个轨道的合集也是 𝐺 不变的。当集合 𝑌 是 𝐺 不变时，𝐺 也是 𝑌 的对称群。
已知 𝐺 是 𝑋 的变换群，那么对于 𝑋 的任意子集 𝑌，总可以找到 𝐺 的一个子群 𝐻 使得该子集是 𝐻 不变的，即𝐻 是 𝑌 的变换群。因为至少平庸子群 $\{𝑒\}$ 肯定是𝑌 的变换群。

### 正𝑛边形对称群

<mark style="background: #FF5582A6;">正 𝑛 边形的对称群</mark> $D_n$ 有 2𝑛 个元素，其中 𝑛 个构成循环子群 $𝑍 = \{𝑇, 𝑇^{2},\cdots, 𝑇^{n} = 𝑒\}$，而其余 𝑛 个元素对应绕 𝑛 个二次转动轴 $𝑆_{i}(𝑖 = 𝑗 \mod{n} )$ 转角度 𝜋 。设转动轴 $𝑆_{i}$ 为逆时针排列，记这些二次转动群元为 $𝑍_{2}= \{𝑒, 𝑆_{i}\}$。
则乘法表如下：
$$\begin{aligned}
&&T^n=e,\quad&S_i^2=e\\
&TS_i=S_{i+1},&T=S_{i+1}S_i=S_iS_{i-1},&&S_iT=S_{i-1},\\
&T^kS_i=S_{i+k},&T^k=S_{i+k}S_i=S_iS_{i-k},&&S_iT^k=S_{i-k}.
\end{aligned}$$

### 迷向子群

定义1.16 设𝐺 是 𝑋 上的变换群，而 𝑥 ∈ 𝑋 是 𝑋 内一点。
若 𝐺 的子群 $𝐺^{x}$ 保持 𝑥 不变，
$$𝐺^{x} = \{ℎ ∈ 𝐺 |ℎ𝑥 = 𝑥 \}.$$
则称 $𝐺^{x}$ 为 𝐺 对 𝑥 的<mark style="background: #FF5582A6;">迷向子群</mark> (isotropy subgroup)。
在前面 𝐷3 群的例子中，使得 𝑌 = {𝐴} 或{𝐶} 不变的迷向子群 $𝐺^{A} = 𝐺^{C} = \{𝑒, 𝑏\}$ , 而使得 𝑌 = {𝐵} 或{𝐷} 不变的迷向子群 $𝐺^{B} = 𝐺^{D} = \{𝑒, 𝑎\}$.

定理1.8 设 $𝐺^{x}$ 是𝐺 对 𝑥 的迷向子群，则 $𝐺^{x}$ 的每一个左陪集把点 𝑥 映为 𝑋 中一个特定的点 𝑦。也就是说，含 𝑥 的 𝐺 轨道上的点和 $𝐺^{x}$ 的左陪集间是一一对应的。

## 5.4 量子场论中的应用

自发对称性破缺？与迷向子群关系。
不自发对称性破缺
$$G^{\phi_{0} }=G$$
$\neq$ :自发对称性破缺

在量子场论中，量子场往往是被变换群作用的集合 $𝑋_{i}$，而理论的作用量(或拉格朗日量)是由 $𝑋_{i}$ 组合出来的不变量 $S[X_i]$，即对
$$\forall g\in G,X_i\rightarrow Y_i=gX_i,S[X_i]\rightarrow S[Y_i]=S[X_i]$$ 

通常，物理系统不仅 $S[X_i]$ 是不变的，而且其最低能态处于$𝑋_{i}=0$ 处，而该处是 𝐺 变换下不变的：$𝑔𝑂 = 𝑂$，所以其迷向子群为 𝐺 本身。但如果系统的最低能态处于其中某个场 $𝑋_i =𝑋_0 ≠ 0$ 的位置，则 𝐺 往往会生成一个过 $𝑋_{0}$ 的轨道，轨道上与 $𝑋_{0}$ 处具有相同的能量。仅某个子群 $G^{X_0}$ 是保持 $𝑋_{0}$ 不变的迷向子群，此时就说发生了<mark style="background: #FF5582A6;">自发对称性破缺</mark>。
