
- 衡量随机变量取值平均水平的一个重要数字特征.
- 在直观上可以理解为随机变量在大量重复试验中观测值的算术平均数的极限.

## 定义

```ad-def
**离散随机变量的期望**:

若随机变量 $X$ 的概率分布为 $P(X = x_i) = p_i$, 其中 $i = 1, 2, \dots$, 则 $X$ 的期望定义为:
$$E[X] = \sum_{i} x_i p_i$$
前提是该级数绝对收敛, 即 $\sum_{i} |x_i| p_i < \infty$.
```

```ad-def
**连续随机变量的期望**:

若随机变量 $X$ 具有概率密度函数 $f(x)$, 则其期望定义为:
$$E[X] = \int_{-\infty}^{\infty} x f(x) dx$$
同样要求该积分绝对收敛, 即 $\int_{-\infty}^{\infty} |x| f(x) dx < \infty$.
```

## 期望的性质

1. 线性: $E[aX + bY] = aE[X] + bE[Y]$ ;
2. 常数 $c$ 的期望: $E[c] = c$ ;
3. 独立随机变量乘积的期望 $E[XY] = E[X]E[Y]$
4. 单调性: 若随机变量 $X$ 与 $Y$ 满足 $X \le Y$ (即在所有样本点上均成立), 则 $E[X] \le E[Y]$.

## 期望的意义

*   物理意义: 如果将概率分布看作质量分布, 那么期望 $E[X]$ 对应于该分布的质心 (Center of Mass).
*   统计意义: 在大数定律的支持下, 期望代表了长期实验结果的平均值. 它是描述随机变量分布中心位置的最基本指标.

## 随机变量函数的期望 (无意识统计学家法则, LOTUS)

若 $Y = g(X)$ 是随机变量 $X$ 的函数, 则不需要先求出 $Y$ 的分布, 可以直接通过 $X$ 的分布计算 $Y$ 的期望:

- 离散型: $E[g(X)] = \sum_{i} g(x_i) p_i$
- 连续型: $E[g(X)] = \int_{-\infty}^{\infty} g(x) f(x) dx$

## 常见分布的期望

*   伯努利分布 $B(1, p)$: $E[X] = p$
*   二项分布 $B(n, p)$: $E[X] = np$
*   泊松分布 $P(\lambda)$: $E[X] = \lambda$
*   均匀分布 $U(a, b)$: $E[X] = \frac{a+b}{2}$
*   指数分布 $Exp(\lambda)$: $E[X] = \frac{1}{\lambda}$
*   正态分布 $N(\mu, \sigma^2)$: $E[X] = \mu$

如果期望对应的级数或积分不绝对收敛 (例如柯西分布 Cauchy Distribution), 则称该随机变量的期望不存在.
