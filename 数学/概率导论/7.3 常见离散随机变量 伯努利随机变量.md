
- 描述一个只可能有两种结果 (通常标记为"成功"或"失败") 的单次随机试验.
- 也称两点分布

### 1. 定义

```ad-def
**伯努利随机变量 (Bernoulli Distribution)**:

若随机变量 X 只能取两个值: 0 和 1, 且其取值的概率如下:
- $P(X = 1) = p$ (称为成功的概率, 其中 $0 < p < 1$
- $P(X = 0) = 1 - p$ (通常记为 $q$, 即失败的概率)

那么称随机变量 $X$ 服从参数为 $p$ 的伯努利分布, 记作 $X \sim Bernoulli(p)$ 或 $X \sim B(1, p)$.
```

```ad-note
**伯努利随机变量的概率分布质量函数:**

其概率质量函数 (PMF) 为:
$$P(X = k) = p^k (1-p)^{1-k}, \quad k \in \{0, 1\}$$
```

### 2. 数字特征

*   期望 (Expectation):
  $$E[X] = 1 \cdot p + 0 \cdot (1-p) = p$$


*   方差 (Variance):
    $$Var(X) = E[X^2] - (E[X])^2 = p - p^2 = p(1-p)$$
    当 p = 0.5 时 (如抛一枚均匀硬币), 方差最大, 此时不确定性最高; 当 p 接近 0 或 1 时, 方差变小, 结果更具确定性.

*   高阶矩:
    由于 $X$ 只能取 0 或 1, 因此对于任意正整数 $n$, 都有 $X^n = X$. 故 $E[X^n] = p$.

### 3. 与二项分布的关系

伯努利分布与二项分布 (Binomial Distribution) 之间存在紧密的联系:
*   伯努利分布是二项分布 $B(n, p)$ 在试验次数 $n=1$ 时的特例.
*   反之, 二项分布可以看作是 $n$ 个相互独立且同分布的伯努利随机变量之和. 即若 $X_1, X_2, ..., X_n$ 独立且均服从 $Bernoulli(p)$, 则 $Y = \sum X_i$ 服从二项分布 $B(n, p)$.

### 4. 典型应用场景

任何只有两种对立结果的单次随机事件都可以用伯努利分布来建模:
*   抛硬币: 正面记为 1, 反面记为 0.
*   质量检测: 产品合格记为 1, 次品记为 0.
*   医学诊断: 患病记为 1, 未患病记为 0.
*   机器学习: 在逻辑回归 (Logistic Regression) 中, 样本的标签通常被假设服从伯努利分布, 模型的目标即是预测参数 p (即属于正类的概率).

### 5. 总结

伯努利分布虽然简单, 但它是构建复杂离散分布模型的基石. 理解伯努利分布对于掌握二项分布、几何分布以及负二项分布等概念至关重要.
