
```ad-def
**连续随机变量**:

如果对于随机变量 $X$, 存在一个非负可积函数 $f(x)$, 使得对于任意实数 $a \le b$, 随机变量落在区间 $[a, b]$ 内的概率可以表示为 $f(x)$ 在该区间上的定积分, 即:
$$P(a \le X \le b) = \int_{a}^{b} f(x) dx$$
则称 $X$ 为连续型随机变量.
```

- 连续随机变量 (Continuous Random Variable) 是概率论中对应于"测量"而非"计数"的一类随机变量. 
- 连续随机变量可以在某个区间 (有限或无限) 内取任意实数值.

```ad-note
连续随机变量 $X$ 的单点概率为 0.
$$P(X = c) = 0$$
```

*   从几何上看: 概率对应于 PDF 曲线下方的面积. 单个点 $x=c$ 对应的是一条垂直线段, 线段的面积为 0.
*   推论: 对于连续随机变量, 区间端点是否包含在内不影响概率值. 即:
$$P(a \le X \le b) = P(a < X \le b) = P(a \le X < b) = P(a < X < b)$$.

常见的连续型分布:
1.  均匀分布 (Uniform Distribution), $U(a, b)$
2.  正态分布 (Normal / Gaussian Distribution), $N(\mu, \sigma^2)$
3.  指数分布 (Exponential Distribution), $Exp(\lambda)$
4.  其他常见分布
    *   Gamma 分布: 指数分布的推广.
    *   Beta 分布: 定义在 [0, 1] 区间上, 常用于贝叶斯统计中的概率建模.
    *   卡方分布 ($\chi^2$), t 分布, F 分布: 统计推断 (假设检验) 中的三大抽样分布.
