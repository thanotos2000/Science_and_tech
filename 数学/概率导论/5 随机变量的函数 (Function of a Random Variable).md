
## 什么是随机变量的函数

- 如果我们有一个已知的随机变量 $X$, 并且有一个确定的数学函数 $g(x)$, 也就是规则, 那么我们可以构造一个新的变量 $Y = g(X)$.
-  由于 $X$ 的取值是随机的, 经过函数 $g$ 变换后, $Y$ 的取值也是随机的, 因此 $Y$ 本身也是一个随机变量.

![[Pasted image 20251228122221.png]]

```ad-def
**随机变量的函数**:

设 $X$ 是定义在样本空间 $\Omega$ 上的随机变量. 设 $g: \mathbb{R} \to \mathbb{R}$ 是一个实值函数 (严格来说需为**博雷尔可测函数**, 通常的连续函数或分段连续函数均满足).

定义一个新的随机变量 $Y$:
$$Y = g(X)$$

这意味着, 对于样本空间中的每一个样本点 $\omega$, 新变量的取值为:
$$Y(\omega) = g(X(\omega))$$
```

*   **确定性变换, 随机性输入**: 函数 $g(\cdot)$ 本身是确定随机性的. 随机性完全来源于输入变量 $X$.
*   **分布的传递**: 通常已知 $X$ 的概率分布, 问题的关键在于如何求出变换后 $Y$ 的概率分布.

## 如何求 $Y$ 的分布?

### 离散情形

- 如果 $X$ 是离散的, 那么 $Y$ 也是离散的.
- 计算方法: **合并概率**.

```ad-note
**合并概率法**:
	1.  确定 $Y$ 的所有可能取值.
	2.  对于 $Y$ 的每一个取值 $y$, 找出所有满足 $g(x) = y$ 的 $x$.
	3.  将这些 $x$ 对应的概率相加.


$$P(Y = y) = \sum_{x: g(x) = y} P(X = x)$$
```

```ad-example
**如何求离散随机变量的函数的PMF?**

$Y = X^2$, $X$的分布列由下式给出:
$$p_X(x)=\begin{cases}1/9,&\text{若 }x\text{ 是 }[-4,4]\text{ 中的整数},\\0,&\text{其他}.\end{cases}$$
如何求 $Y$ 的概率质量函数 PMF?

由于 $Y$ 的值域为 $y = 0, 1, 2, 3, 4$, 对于值域中的任意 $y$, 只需将满足 $|x| = y$ 的所有 $p_X (x)$ 的值相加, 就可以得到 $p_Y (y)$ 的值.
$$\begin{aligned}
&p_Y(0)=p_X(0)=\frac19\\
&p_Y(1)=p_X(-1)+p_X(1)=\frac{2}{9}\\
&\cdots\cdots
\end{aligned}$$
于是,
$$\begin{aligned}&p_Y(y)=\begin{cases}2/9,&\text{若 }y=1,2,3,4,\\[2ex]1/9,&\text{若 }y=0,\\[2ex]0,&\text{其他}.\end{cases}\end{aligned}$$

```

### 连续情形

```ad-note
**方法1: 分布函数法 (CDF Method, 最通用)**
1. 根据定义写出 CDF: $F_Y(y) = P(Y \le y) = P(g(X) \le y)$.
2. 对 $F_Y(y)$ 求导得到 PDF: $f_Y(y) = F'_Y(y)$.
3. 利用 $X$ 的 CDF 或 PDF 进行计算得到 $F_Y(y)$.
4. 将不等式 $g(X) \le y$ 转化为关于 $X$ 的不等式.
```

```ad-note
**方法 2: 变换公式法 (Jacobian Method)** 

如果 $g(x)$ 是单调函数 (严格递增或递减) 且可导, 可以直接套用公式: $$f_Y(y) = f_X(x) \left| \frac{dx}{dy} \right| = f_X(g^{-1}(y)) \left| \frac{d}{dy} g^{-1}(y) \right|$$

其中, $g^{-1}(x)$是反函数. $\left| \frac{dx}{dy} \right|​$ 为雅可比行列式 (在一维情形下即导数的绝对值).
```
