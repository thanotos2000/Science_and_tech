# 激光

LASER: Light Amplification by Stimulated Emission of Radiation

玻尔兹曼分布:
$$\frac{N_2}{N_1}=\exp\left(\frac{-(E_2-E_1)}{kT}\right)$$

![[Pasted image 20231109212340.png]]

吸收

一个低能级的电子吸收一定能量的光子跃迁到高能级.
$$\frac{dN_1}{dt}=-BN_1I$$

![[Pasted image 20231109212710.png]]


- I : 光强
- N1 (N2) : 低(高)能级上的粒子数


自发辐射

一个高能级电子向下跃迁, 放出一定频率的光子.
$$\frac{dN_2}{dt}=-AN_2=-\frac{N_2}{\tau_{21}}$$

![[Pasted image 20231109212911.png]]

- $\tau_{21}=\dfrac{1}{A}$ : 上能级寿命.
	- 对应短的上能级寿命, 光子的发射被称为<mark style="background: #FF5582A6;">荧光</mark>。
	- 对于某些被禁止的跃迁，能级寿命很长, 可以是几个小时，对应于<mark style="background: #FF5582A6;">磷光</mark>。


受激发射

一个光子激发一个高能级的电子跃迁到低能级, 放出第二个光子. 
$$\frac{dN_{2}}{dt}=-BN_2I$$

![[Pasted image 20231109213711.png]]

- 第二个光子是前一个光子的 "克隆", 二者具有相同的频率, 偏振, 传播方向等.

粒子数反转:
$$N_2>N_1$$



忽略自发辐射, $I=I(z-ct)$
$$\frac{dI}{dt}=c\frac{dI}{dz}\propto BN_2I-BN_{1I}\propto B[N_2-N_1]I$$
 解
 $$I(z)=I(0)\exp\bigl\{\sigma\bigl[N_2-N_1\bigr]z\bigr\}$$
系数 $\sigma =B\hbar \omega$ 是吸收/增益交叉项

- 光强的变化函数是一个指数函数, 光强增加还是衰减取决于上能级粒子数&下能级粒子数的大小 $N_2-N_1$.	
- $N_2<N_1$ : 吸收, 光经过材料的过程中被吸收衰减了. 如超构玻璃, 可见光可透射, 但紫外光或红外光被吸收
- $N_2>N_1$ : 放大
$$G\equiv\exp\left\{\sigma\bigl[N_{2}-N_{1}\bigr]L\right\}=\exp(gL)$$
- $N_2>N_1$ : $g\equiv [N_2-N_1]\sigma$
- $N_2<N_1$ : $\alpha \equiv [N_1-N_2]\sigma$

为了获得光放大: G>1, 
$$B N_2 I > B N_1 I$$
粒子数反转:
$$\Delta N\equiv N_1-N_2<0$$
这种情形不会自然出现, 这种状态是不被玻尔兹曼分布所允许的, 因此它是一种非平衡态.

![[Pasted image 20231109220728.png]]

为了实现粒子数反转, 或许我们可以选取某两个特殊的能级使其实现粒子数反转.

![[Pasted image 20231109220734.png]]

四能级系统的光泵浦: 

![[Pasted image 20231109220826.png]]

- 0号能级到3号能级间利用强的808nm的光将0能级上的粒子抽运泵浦到3号能级上.
- 能级3和能级2通过某种方式耦合在一起, 使粒子从能级3很快地"掉落"到能级2, 
- 1能级的寿命很短, 能快速的跃迁到0能级.
- 最后实现了能级2到能级1的粒子数反转, 实现1064 nm的光子.

通过将该过程放入谐振腔中, 光来回穿过增益介质光放大, 

![[Pasted image 20231109221511.png]]

激光3要素:

![[Pasted image 20231109221700.png]]

- 泵浦源: 提供能量 (optical pumping)
- 增益介质: 光放大 (泵浦能量到光的能量) (population inversion)
- 谐振腔: 让光不断通过增益介质, 将其储存的能量通过激光的方式输出到腔外.
