下面给出在 UPPE 框架下对“准直高斯光束经球面镜、以非零入射角反射后聚焦到气体池”的建模思路与步骤。要点是：镜面反射改变了光束传播方向并引入像散（tangential / sagittal 两个不同焦距），同时可能带来偏振与频率依赖的反射相位。UPPE是沿单一 z 轴的单向传播模型，最稳妥的做法是把镜子当作“薄元件”的边界条件，在镜后定义初始场，然后沿镜后新光轴正向传播到气体池。

## 一、坐标与基本假设

- 选择镜后“反射光束的中心传播方向”为 UPPE 的 z 轴；把入射面所在平面定义为 x 方向（tangential plane），与其垂直的方向为 y (sagittal plane)。这样镜后不需要再引入线性相位的“倾斜”，简化传播。
- 如果你的UPPE实现是轴对称（仅 r 坐标），那么非零入射角引入的像散会破坏轴对称；建议使用具有二维横向频域/时域（kx, ky 或 x, y）的UPPE版本。如果必须用轴对称近似，参见下面的近似判据。

## 二、球面镜的像散焦距（非零入射角）

- 设球面镜曲率半径为 $R$，反射入射角为 $θ$（相对镜面法线）。
- 在小像差、近轴近似下，有效焦距在两主截面不同：
  - tangential（入射面内，x方向）：$f_x = (R/2) · \cosθ$
  - sagittal（垂直入射面，y方向）：$f_y = (R/2) / \cosθ$
- 因此，x方向的焦点更近，y方向更远，焦点间距（准直入射近似下）约为$Δz_{ast} ≈ (R/2) · (1/cosθ − cosθ)$。

## 三、将镜子当作“薄元件”施加到初始场

- 设镜面处入射是准直高斯光束，镜面处光斑半径为 $w(z)$（在镜面坐标的x,y方向可近似相同）。波长为 $λ$。
- 在镜面后定义初始场的振幅与相位（频域或时域包络皆可）。镜子的作用可用一个各向异性的二次相位（薄透镜）来实现：
  - 相位因子：$φ(x,y,ω) = − k(ω) · [ \dfrac{x^2}{2f_x} + \dfrac{y^2}{2f_y} ]$
  - 如果需要考虑镜面有限口径及非零入射角导致的投影椭圆光阑，可乘以一个椭圆光阑 $A(x,y)$（半短轴约为实际镜半径乘以 $\cosθ$）。
- 偏振与频率依赖的反射：
  - 若镜为金属且 $θ$ 不太大，$r_s(ω,θ) ≈ r_p(ω,θ) ≈ 1$，相位差很小，可忽略。
  - 若是介质高反镜（多层膜），应对 Ex（s偏振）与 Ey（p偏振）分别乘以复杂反射系数 $r_s(ω,θ)、r_p(ω,θ)$，它们同时引入幅度与相位（群延时）差，可能导致脉冲前沿倾斜或弱的色散；在矢量 UPPE 或标量双仿真中体现。

## 四、用ABCD/q参数更精确地得到焦点位置与腰斑

- 对每个主轴独立使用高斯光束 $q$ 参数变换（薄镜等效薄透镜），更准确地给出焦点位置与腰斑大小，尤其当入射并非“完美准直”：
  - 镜后 $q_{out,j} = \dfrac{q_{in,j}}{1 − q_{in,j} / f_{j}}$，其中, $j ∈ {x,y}$。
  - 对镜面处准直高斯：$q_{in,j} ≈ i z_R$，$z_R = π \dfrac{w_m^2}{λ}$。
  - 之后自由空间传播距离z：$q_j(z) = q_{out,j} + z$。
  - 腰斑与曲率：
    - $w_j(z) = \sqrt{\dfrac{\lambda}{\pi} · \rm{Im}[q_j(z)] }$
    - $R_j(z) = 1 / \rm{Re}[ \dfrac{1}{q_{j}(z)}]$
  - 腰位置在使 $\rm{Re}[1/q_j(z)] = 0$ 的 z 处；对准直入射且 $f_j ≫ λ$ 的常见情况，腰位置近似在 $z_{0,j} ≈ f_j$，腰斑大小近似 $w_{0,j} ≈ \dfrac{λ f_j}{π w_m}$。
- 焦点分离的直观近似（准直入射）：$z_{0,x} ≈ f_x，z_{0,y} ≈ f_y$。

五、在UPPE中设置初始场与传播
- 初始平面选择：
  - 简便法：把 $z=0$ 设为“镜后刚反射”的平面，场为入射高斯乘上述镜相位与反射系数，然后在线性介质（空气/真空）中传播到气体池入口；随后切换介质参数为气体（色散、非线性、可能的吸收/电离）。
  - 若几何上更方便，也可把 $z=0$ 设在气体池入口，直接用 q 参数算出该平面上的横向振幅与相位分布（包含像散曲率），作为初始条件。
- 二维横向：
  - 使用 kx-ky 或 x-y 的二维网格，避免轴对称误差。把主轴对齐入射面与其垂直方向。
  - 网格尺寸需覆盖最大光斑与衍射扩展；采样满足最高空间频率（与最强聚焦处的数值孔径相关）。
- 介质与非线性：
  - 在气体池段启用气体的线性色散（$n(ω)$）、非线性（Kerr $n_2$，Raman，如需要）以及电离模型（如强场）。
  - 对非零入射角，若气体池的几何长度是沿装置轴，而光束是斜穿，请将UPPE的传播长度设为沿光束路径的实际长度（即z轴长度应为光程）。

六、是否可以用轴对称近似的判据
- 像散造成两主轴焦点分离 $Δz_{ast} ≈ f(1/cosθ − cosθ) ≈ f θ^2$（小角近似）。
- 若 $Δz_{ast}$ ≪ 有效瑞利长度 $z_{R,eff}$（例如$z_{R,eff}$ 取两主轴的几何平均），则轴对称近似带来的误差可能可接受；否则建议使用二维UPPE。
- 注：几何平均焦距 $\sqrt{f_x f_y} = f$（正常入射的焦距），因此在小角度时，很多宏观量看起来“接近f”，但细节（峰值强度、非线性触发位置）仍会受像散影响。

七、常见细节与检查
- 圆最小色散圈（circle of least confusion）：像散下在两焦线之间存在一个最佳折中面，实际峰值强度可能出现在该面附近；可通过线性传播测试找到。
- 有限镜孔径与投影椭圆：在 x 方向（入射面内）有效口径缩为 $D·cosθ$，必要时加入光阑以评估衍射尾和像差。
- 大角度时的像差：倾斜使用球面镜还会引入彗差与球差（超出二次相位），若光束口径相对镜$R$较大或$θ$较大，可在镜相位上叠加四阶项或直接用波前追迹得到的相位地图。
- 频率依赖：若脉冲宽带且镜为介质多层膜，$r_s/p(ω,θ)$ 的频率依赖可能在UPPE中需要作为一个线性算符（对每个 $ω$ 施加）。
- 验证：先关掉非线性，仅线性传播，检查在气体池中的x、y方向光斑尺寸和焦点位置是否与q参数预测一致；再开启非线性。

八、简要的实现步骤清单
- 确定参数：$R$、$θ$、$λ$、镜面处光斑 $w_m$、到气体池入口的距离$L$、气体的线性/非线性参数。
- 计算：$f_x = (R/2)\cosθ，f_y = (R/2)/\cosθ$。
- 初始场（镜后）：
$$\boxed{E(x,y,ω,0) = E_0(ω) · e^{−(x^2 + y^2)/w_m^2} · e^{−i k(ω) [ \frac{x^2}{2 f_x} + \frac{y^2}{2 f_y} ]} · [\text{偏振反射系数}]}$$
- 可加入椭圆光阑 A(x,y) 与任何已知的镜面像差相位。
- 线性传播到池入口（真空/空气），切换介质后用UPPE继续传播。
- 结果评估：x、y方向的 w(z)、焦点位置、峰值强度，必要时微调镜角度或距离以把峰值强度对准期望位置。
